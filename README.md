# Istanbul Cafe Bot & Web Management

Istanbul Cafe uchun Telegram Bot va Veb Boshqaruv (Admin) Paneli.

## Xususiyatlari
- 🤖 **Telegram Bot**: Taomlarni ko'rish, savatga qo'shish va buyurtma berish.
- 📱 **Telegram WebApp**: Interaktiv va zamonaviy menyu orqali qulay buyurtma.
- 💼 **Admin Panel**: Real vaqt rejimida tushumlar, kunlik buyurtmalar va taomlar hisoboti.
- 💳 **To'lovlar**: Payme / Click orqali to'lov cheklarini yuklash va tasdiqlash.

## Ishga tushirish
```bash
pip install -r requirements.txt
python istanbul_cafe_bot.py
```
